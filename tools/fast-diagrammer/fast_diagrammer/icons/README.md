# Icons

The 13 legacy networking glyphs and the 24 newer glyphs in this directory are
the author's own drawings, made with Google-owned tooling and licensed under
Apache 2.0 like the rest of this repository. They are not the official Google
Cloud icon set.

`icons.json` is generated from the `*.svg` files by `tools/build_icons.py`
(`--check` fails when it is stale). The legacy entries are copied verbatim
from the existing `icons.json` rather than regenerated, because the
2-networking golden outputs depend on their exact markup.
